# Ashmane mesh

`ashmane.glb` is Rico Cilliers’ [Horse Statue 01](https://polyhaven.com/a/horse_statue_01) (Poly Haven, CC0), 2k PBR, Blender-cleaned:

- wooden puck and ceramic disc removed
- loose photogrammetry islands kept as separate meshes
- origin on the hind hooves, nose toward +Z, height about 1.72 m
- roughness raised so the dusk HDRI reads hide, not shop glaze

See [ATTRIBUTION.md](../../ATTRIBUTION.md) and `scripts/clean-ashmane.py`.
