## Issue 1: explode-assembly — Scene Props in Frame (CRITICAL)

### Problem (from production screenshot)
The `model3.glb` asset includes the full tesla-3d-showcase scene:
- ❌ Traffic light pole in foreground
- ❌ Large speakers and picnic props
- ❌ Room walls/floor visible
- ❌ Car parts scattered (door floating left, wheels piled right)
- ❌ Bright grey room instead of dark studio
- ❌ At explode=0%, car not fully assembled

**Root cause**: Code was traversing ALL meshes in the GLB scene without filtering, including non-car props.

### Fix Applied

**1. Added mesh filtering** (`CarModel.tsx`):
```typescript
const EXCLUDE_KEYWORDS = [
  'traffic', 'light_pole', 'pole', 'sign', 'cone', 'barrier',
  'speaker', 'table', 'chair', 'cactus', 'kayak', 'train',
  'floor', 'wall', 'ceiling', 'room', 'ground_plane', 'plane',
  'picnic', 'bench', 'prop', 'decoration', 'fence', 
  'tire_stack', 'tire_prop', 'background', 'environment',
  'light_001', 'light_002', 'light_003',
];

function shouldIncludeMesh(name: string): boolean {
  const lowerName = name.toLowerCase();
  
  // Exclude known props/scene objects
  if (EXCLUDE_KEYWORDS.some(kw => lowerName.includes(kw))) {
    return false;
  }
  
  // Include if matches car system keywords
  for (const keywords of Object.values(SYSTEM_KEYWORDS)) {
    if (keywords.some(kw => lowerName.includes(kw))) {
      return true;
    }
  }
  
  return !lowerName.includes('scene') && 
         !lowerName.includes('root') &&
         lowerName.length > 0;
}
```

Now traverse only includes car meshes:
```typescript
scene.traverse((node: any) => {
  if (!shouldIncludeMesh(node.name || '')) {
    excluded.push(node.name);
    return; // Skip this mesh
  }
  // ... rest of logic
});
```

**2. Enhanced studio lighting** (`Scene.tsx`):
- Changed background from `#0a0c0e` → `#000000` (pure black)
- Updated Environment from `night` → `studio`
- Added 3-point lighting:
  - Key light: Main directional from top-left
  - Fill light: Softer directional from right (blue tint)
  - Rim light: Edge definition from behind
  - Top spot: Accent from above
- Darkened ground plane: `#1a1d23` → `#0a0a0a`
- Made grid more subtle: `#2a3038/#1e2228` → `#1a1a1a/#0f0f0f`
- Adjusted camera: position `[-5,3,7]` → `[-6,3,8]`, FOV `45` → `40` (frames sedan better)

### Explode Visual QA: ✅ FILTER HARDENED

**Critical fix applied** — Hardened mesh filter to **whitelist-only**:

```typescript
// OLD: Fallthrough included unnamed Object_* props
// NEW: ONLY include meshes matching SYSTEM_KEYWORDS or CAR_ROOT_KEYWORDS

function shouldIncludeMesh(name: string): boolean {
  if (!name || name.length === 0) return false;
  
  const lowerName = name.toLowerCase();
  
  // Exclude props FIRST (catches "traffic_light" before "light" matches)
  const EXCLUDE_KEYWORDS = [
    'traffic', 'light_pole', 'speaker', 'table', 'floor', 'wall', 
    'picnic', 'tire_stack', 'object_', // Generic Blender exports
  ];
  if (EXCLUDE_KEYWORDS.some(kw => lowerName.includes(kw))) return false;
  
  // Whitelist: ONLY car system keywords
  for (const keywords of Object.values(SYSTEM_KEYWORDS)) {
    if (keywords.some(kw => lowerName.includes(kw))) return true;
  }
  
  // Whitelist: Known car roots
  if (['model3', 'tesla', 'car', 'vehicle'].some(kw => lowerName.includes(kw))) {
    return true;
  }
  
  // Default: EXCLUDE everything else
  return false;
}
```

**Changes**:
- Exclude tokens checked FIRST (prevents "traffic_light" matching `lights` system)
- Unnamed/generic meshes (`Object_*`) excluded by default
- Only meshes matching car keywords included
